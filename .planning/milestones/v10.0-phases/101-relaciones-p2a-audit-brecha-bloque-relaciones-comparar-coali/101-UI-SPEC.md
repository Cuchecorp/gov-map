# Phase 101 — UI Design Contract

> Visual and interaction contract for RELACIONES P2a — Audit brecha + bloque relaciones (ficha) + `/comparar` + coalición empírica. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase does NOT introduce net-new visual design.** It RE-COMPOSES the existing, régimen-locked `CrossLinkBloque` into a wrapper section and adds ONE new route (`/comparar`) that reuses the same tokens, primitives and copy discipline. Almost every value below is pre-populated from the existing codebase — the contract's job here is to keep the new surfaces inside the locks, not invent.

## Spacing Scale

Declared values (Tailwind default 4px base — all multiples of 4). Phase 101 uses ONLY the subset already in use on the ficha and cross-link surfaces:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | `gap-1` inline (mt-1 between conteo lines) |
| sm | 8px | `gap-2` chip↔link, `mt-2` legend under heading |
| md | 16px | `gap-4` / `mt-4` list top, grid cell gap on the 2×2 relations grid |
| lg | 24px | `md:gap-6` grid gutter on `/comparar` A/B columns (Discretion) |
| xl | 32px | `gap-8` ficha rail↔content grid (existing, untouched) |
| 2xl | 48px | **`mt-12` LOCKED** — the anti-insinuación sibling-section boundary. Every `<section>` that composes relations keeps `mt-12`. |
| 3xl | 64px | page vertical rhythm `py-16` (existing main, untouched) |

**Exceptions:**
- `min-h-11` (44px) touch target on "Ver los N" / "Comparar con…" links — WCAG tap target, already established in `CrossLinkBloque`.

**LOCK — `mt-12` boundary:** The new `<section id="relaciones">` wrapper and any new 5th block (militancia histórica) MUST be siblings at `mt-12`. Wrapping the four existing `CrossLinkBloque` in a grid MUST NOT collapse their internal `mt-12` semantics into a nested container in a way that fuses two domains into one `<article>/<li>`. Grid is a visual 2×2 layout **inside** the relations section; the anti-insinuación frontier stays between the relations section and its neighbors.

## Typography

Existing `var(--text-*)` scale (defined via Tailwind v4 / globals). Phase 101 uses exactly these roles — 3 sizes in active use + 1 display reserved, 2 weights:

| Role | Token / class | Size | Weight | Line Height | Usage |
|------|---------------|------|--------|-------------|-------|
| Body / legend | `text-sm` (`var(--text-sm)`, 14px) | 14px | 400 regular | 1.5 (default) | anti-causal legend, conteo texto, coverage declaration, source+fecha, empty states |
| Row label | `text-base` (`var(--text-base)`, 16px) | 16px | 600 semibold | 1.5 | parlamentario name link in a row, A/B cell value |
| Section heading | `text-xl` (`var(--text-xl)`, 20px) | 20px | 600 semibold | ~1.2 (snug) | `<h2>` "Relaciones con otros parlamentarios", per-eje `<h2>`, `/comparar` axis headings |
| Micro / periodo | `text-xs` (`var(--text-xs)`, 12px) | 12px | 400 (mono for periodo) | 1.4 | periodo `font-mono`, fecha de captura, provenance |

**Weights:** exactly two — `font-normal` (400) and `font-semibold` (600). No other weights. (Matches every existing ficha surface.)

**LOCK:** No literal `text-[…px]` and no ad-hoc `rem`. Only `text-xs/sm/base/lg/xl` classes (which resolve to `var(--text-*)`). The source-scan guard blocks ad-hoc rem (DEBT-05 precedent).

## Color

60/30/10 régimen, all via hsl tokens (cero-hex LOCKED). No new color introduced.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (crema `40 33% 97%`) / `--foreground` | page + relations section surface, body text |
| Secondary (30%) | `--card` / `--muted-foreground` (`222 14% 42%`) | legends, conteo, coverage text, periodo, source lines — everything secondary in a row |
| Accent (10%) | `--accent-product` (petróleo `183 38% 26%`) | **reserved for:** parlamentario name links (`text-accent-product`), "Ver los N" link, "Comparar con…" link, focus-visible outlines (`outline-accent-product`), and the intersection emphasis on `/comparar` ("comparten N comisiones"). NOTHING else. |
| Destructive | `--destructive` | **not used** — Phase 101 has zero destructive actions. |

**Accent reserved for (explicit, closed list):**
1. Links to a parlamentario's ficha (row name).
2. "Ver los N" directory link (when a pre-filtered directory exists).
3. "Comparar con…" CTA link from a ficha.
4. `focus-visible` outline (2px) on all the above.
5. Factual intersection emphasis text on `/comparar` (e.g. the "N comisiones compartidas" figure) — petróleo as a NEUTRAL highlight of a count, **never** as an affinity/warmth signal.

**LOCKS:**
- Petróleo lives ONLY on connectors/links/focus (globals.css §comment). It is NOT a "these two are close/aligned" signal. The intersection figure is a factual count, not a heat/score color.
- **No color encodes ranking, affinity, or ideological position.** No red/green "agree/disagree", no gradient, no heatmap. Anti-DW-NOMINATE lock: not even as an easter egg.
- Dark mode: `--accent-product` pinned via existing tokens; no per-phase dark overrides.

## Interaction & Layout Contract

### Ficha — relations block (REL-02)
- Wrap the four existing `CrossLinkBloque` in `<section id="relaciones" className="mt-12">` with `<h2 className="text-xl font-semibold">Relaciones con otros parlamentarios</h2>` + the group legend + a **responsive 2×2 grid** (`grid grid-cols-1 md:grid-cols-2 gap-4` — 1 col mobile, 2 cols md+).
- **Position:** immediately after the header/bio (above-the-fold), i.e. moved UP from its current position at the end of the content column (currently `page.tsx:283-294`). It should appear before the domain carriles (votos/lobby/etc.) OR in the position the plan determines from the audit — the CONTRACT requirement is above-the-fold, near the identity.
- **`CrossLinkBloque` internals stay INTACT** (LEYENDA verbatim, límite visual 8, honest `total_n`, truncation declared, no partido per row, `return null` on empty). Phase 101 changes ONLY the wrapper and grid placement.
- Add `#relaciones` to the ficha internal nav (`FichaRail` / `construirChips`) if the rail pattern supports a non-carril anchor — deep-linkable `/parlamentario/{id}#relaciones`. `scroll-margin-top: 5rem` applies automatically.
- Each of the four blocks keeps its own `<Suspense fallback={null}>` for independent streaming (existing pattern). The grid must not force all four to resolve together.

### `/comparar` route (REL-03)
- **URL:** `/comparar?a=<id>&b=<id>` — query params, canonical **alphabetical order** of ids so the URL is stable regardless of selection order. No params → empty selectors (no 404).
- **Gotcha (Phase 45):** `notFound()` MUST NOT run before `searchParams` is read (a pre-searchParams `notFound` bakes the route static → 500 with dynamic content). Use `export const dynamic = "force-dynamic"` on the route, mirroring the ficha.
- **Selectors:** two server-friendly selectors reusing the existing directory RPC `parlamentarios_publico_v2`, name search. From a ficha, "Comparar con otro parlamentario" pre-fills slot A.
- **Render:** side-by-side A/B **table per axis** (4 axes). Each axis row: A column value, B column value, and a factual intersection line ("Comparten N: …"). Two-column layout `md:grid-cols-2` for A/B, intersection spanning full width below. Each datum carries source + fecha; empty axes declare absence. Alphabetical within lists, zero ranking/score.
- **Data channel:** read existing RPCs server-side (`militancias_de_parlamentario`, `comisiones_de_parlamentario`, `coautores_de_parlamentario`, `parlamentarios_publico_v2`) and compute the intersection on the SERVER. A NEW RPC (`militancia_historica_compartida`) is created ONLY if the audit (Plan 01) shows the intersection can't be derived from existing RPCs — decided with evidence, following the 0061 secure-RPC pattern (secdef, `search_path=''`, `statement_timeout`, LIMIT bounded, drop-before-create, double-revoke CERO grant, `PUBLIC_RPC_ALLOWLIST`, pgTAP).

### Coalición (REL-05) — conditional
- If the empirical probe (curl/BrowserOS on Servel pactos / comités Senado) finds a stable official source machable by deterministic name → factual chip/field next to partido on the ficha + an axis on `/comparar`, each with source+fecha. **No map, no bloc grouping, no spatial layout.**
- If not viable → DEFERRED, documented in `101-AUDIT-RELACIONES.md` with evidence. No surface rendered.

### Loading & absence
- Skeletons for `/comparar` shape-matched to the A/B table (mirror existing skeleton discipline: intro line + N axis rows). Anti-CLS.
- Absence is ALWAYS declared with "en las fuentes consultadas al {fecha}", never silent, never implied as "no relationship exists".
