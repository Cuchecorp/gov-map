# Phase 100 — UI Design Contract

> Visual and interaction contract for the landing **panel de actualidad**. This is a
> **MODIFY-existing-design** phase: the design system (v8.0 bento, civic hsl() tokens,
> typography whitelist, cero-hex, Tailwind v4 `[var(--t)]`, `force-dynamic`) already
> exists and is REUSED verbatim. The contract below arranges the Phase-99 panel signals
> inside that system — it does NOT invent a new design language.
> Generated by gsd-ui-researcher; verified by gsd-ui-checker; cold-read gated by BrowserOS
> against the real deploy.

---

## 0. Scope & Source of Truth

**What changes:** the product-centric BODY of `app/app/page.tsx` (the three
`actualidad-module.tsx` tiles Votado/Urgencias/Frescura, which are the GERM) is
replaced/extended by a **panel de actualidad** that reads the precomputed signals of
`actualidad_senal` via the bounded RPC `actualidad_senales_panel(p_tipo)` (server-side,
service_role, Camino A).

**What does NOT change:**
- The home URL (`/`) — SEO/anchors intact; `:where([id]) { scroll-margin-top: 5rem }` preserved (gotcha v8.0).
- The hero tile (kicker + h1 + SearchBox) — copy LOCKED byte-identical unless the operator authorizes (v8.1 D1: operator has annulled copy changes before).
- The accent "¿Cómo leer esto?" tile → `/sobre` and the 3 entry tiles (`/buscar`, `/parlamentarios`, `/agenda`) — LOCKED copy, kept.

**Data contract (Phase 99, LOCKED):** the RPC returns 9 columns per signal row:
`tipo_senal, ventana, conteo, cobertura_camara, materia, cluster_id, fecha_max, supresion_causa, evidencia`.
`tipo_senal ∈ {velocity, nuevos_ingresos, urgencias, agenda_citacion, agenda_sala, archivados, agrupacion_materia}`.
The panel **displays** these; it NEVER recomputes, aggregates on-read, or derives new numbers.

## Spacing Scale

The project uses Tailwind standard steps (multiples of 4) PLUS a hard-whitelisted set of
mockup off-steps enforced by `bento-guards.test.ts` (Guard II). Panel tiles MUST reuse
these — inventing a new arbitrary value fails the guard.

| Token | Value | Usage |
|-------|-------|-------|
| — | 8px (`gap-2`, `mt-2`) | inline chip/label spacing |
| — | 16px (`gap-4`, `p-4`) | default element spacing |
| — | 24px (`p-6`) | **tile inner padding — the panel default** (matches actualidad-module tiles) |
| — | 32px (`p-8`) | hero tile padding (unchanged) |

Exceptions (whitelisted off-steps — reuse, do NOT add new ones without extending `WHITELIST_ARBITRARIOS`):

| Arbitrary | Where reused in panel |
|-----------|----------------------|
| `gap-[14px]` | BentoGrid gap + item list gap |
| `gap-x-[22px]` | frescura/strip horizontal spacing |
| `px-[9px]` | pill/chip padding (materia label, ventana chip) |
| `py-[18px]` | strip vertical padding |
| `w-[3px]` + `rounded-[2px]` | civic 3px provenance bar (cámara color) |
| `max-w-[1120px]` | bento container (page.tsx) |

Touch targets: interactive rows/links keep `min-h-11` (44px) — reuse the `inline-flex min-h-11 items-center` idiom from the germ.

## Typography

Sizes are a HARD whitelist (`bento-guards.test.ts` Guard II). Panel copy MUST use only these — any other `text-[Npx]` fails the guard.

| Role | Size | Weight | Line Height | Class |
|------|------|--------|-------------|-------|
| Tile heading | 18px | 600 (semibold) | snug (~1.375) | `text-lg font-semibold` |
| Item title | 15px | 600 | snug | `text-[15px] font-semibold leading-snug` |
| Body / factual sentence | 13px | 400 | normal | `text-[13px]` |
| Empty/suppression body | 14px | 400 | normal (1.5) | `text-sm text-muted-foreground` |
| Kicker / chip / provenance | 11px | 500 (medium) | normal | `text-[11px] font-mono` (+ `tracking-[0.08em]` on kicker only) |
| Numeric tally / date / boletín | inherits size | 400 | — | `font-mono` (ALWAYS mono for numbers/dates/boletines) |

Two weights only: 400 (regular) + 600 (semibold). No 500-except the mono kicker/chip (`font-medium`, existing pattern). Hero `h1` (`text-4xl/5xl font-semibold`) is UNCHANGED.

## Color

60/30/10 split is LOCKED (DESIGN-SYSTEM §1.1). Tokens are hsl() baked — **cero-hex** is a formal candado (`bento-guards.test.ts` Guard I): NO hex literal may appear in any panel surface.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (crema `40 33% 97%`) | page surface |
| Secondary (30%) | `--card` (`40 30% 99%`) + `--border` (`40 16% 86%`) | every tile (`bg-card border border-border`) |
| Accent (10%) | `--accent-product` (petróleo `183 38% 26%`) | see reserved list |
| Destructive | `--destructive` (`0 72% 42%`) | **not used in this phase** (no destructive actions on the panel) |

**Accent (petróleo) reserved for — explicit list, never "all interactive elements":**
- Connector/source links (`Fuente ↗`, `Ver proyecto →`) — `text-accent-product underline`.
- Focus ring (`focus-visible:ring-ring`, ring = petróleo).
- Tile hover border (`hover:border-accent-product`).
- Bullet/marker dots (`bg-accent-product`) and the single-diamond entry marker.
- Ventana/tipo chips: `text-accent-product bg-accent-product-soft` (existing pill idiom).
- The one `accent` tile ("¿Cómo leer esto?") fill — unchanged.

**Civic provenance colors (NOT accent — semantic, per-cámara):** the 3px bar and any cámara label use `--camara` (blue `213 94% 38%`) / `--senado` (red `355 65% 38%`), consumed as `bg-[var(--camara)]` / `bg-[var(--senado)]` (Tailwind v4 `[var(--t)]` form — bare `-[--camara]` is INVALID and caught by Guard III). These are provenance-of-source markers, never brand color and never "who is more active" — see Honesty Contract §Anti-ranking.

## Panel Layout (Claude's discretion — arranged within the existing BentoGrid)

The panel replaces the 3-tile germ with signal tiles read from one RPC call
(`actualidad_senales_panel()` with `p_tipo = null` returns all rows; the server component
groups rows by `tipo_senal` in memory — no extra round-trips). DOM order = collapse order.

**BentoGrid arrangement (6-col ≥ md; 1-col < md at 390px):**

| Order | Signal tile | `tipo_senal` | Span | Rationale |
|-------|-------------|--------------|------|-----------|
| 1 | Hero (kicker + h1 + SearchBox) | — | 4 | UNCHANGED |
| 2 | "¿Cómo leer esto?" → /sobre (accent) | — | 2 | UNCHANGED (honesty legend anchor) |
| 3 | **Movimiento reciente** | `velocity` | 4 | ancla del panel; rows per `cobertura_camara` |
| 4 | **Urgencias del Ejecutivo** | `urgencias` | 2 | fechado, aggregate (no cámara cut) |
| 5 | **Agenda próxima** | `agenda_citacion` + `agenda_sala` | 4 | two sub-signals in one tile; `agenda_sala` suppressed → renders `supresion_causa` |
| 6 | **Nuevos ingresos** | `nuevos_ingresos` | 2 | corpus 2022-2026 declared |
| 7 | **Archivos y retiros** | `archivados` | 3 | "movimiento de archivo/retiro fechado", 30d |
| 8 | **Por materia** | `agrupacion_materia` | 3 | factual materia labels; tolerate `(sin materia)` |
| 9 | 3 entry tiles (/buscar, /parlamentarios, /agenda) | — | 2 each | UNCHANGED, below the panel |

Spans sum to full 6-col rows and MUST stay `2 | 4 | 6` (BentoTile only supports those) — for the 3-span pairing (rows 7+8) use `span={2}` + a sibling, or promote to a `span={6}` tile holding both sub-blocks; the executor picks whichever keeps the grid clean. **Do not add new span values to `bentoTileVariants`.**

**Responsive 390px:** BentoGrid collapses to `grid-cols-1`; each tile becomes full-width in DOM order (3→4→5→6→7→8). No horizontal scroll, no dense table. Tile inner padding stays `p-6`. Numeric tallies stay `font-mono` and never wrap mid-number.

### Tile anatomy (every signal tile)

```
┌ BentoTile (default, bg-card, border) ──────────────────────────┐
│ <h2 text-lg font-semibold>  {tile title}                       │
│                                                                 │
│  [3px cívico bar if cobertura_camara is a chamber]  {row body}  │
│    ├ conteo (font-mono) + honest framing phrase                 │
│    ├ ventana / cobertura_camara chip (accent-product-soft)      │
│    └ fuente + fecha_max (font-mono text-[11px] muted)           │
│  … up to N rows (bounded by RPC LIMIT 200; tile shows ≤6)       │
│                                                                 │
│  fuente + "datos al {fecha_max}" footer (ALWAYS present)        │
└─────────────────────────────────────────────────────────────────┘
```

- **Count + honest framing:** render `conteo` in `font-mono`, framed factually: `"{conteo} trámites en 7 días"` (velocity), `"{conteo} urgencias fechadas en 30 días"` (urgencias), `"{conteo} próximas"` (agenda). NEVER "top", "los más", "la cámara más activa".
- **Fuente + fecha:** every tile carries source (`origen`/`dataset` → human label via existing `source-label`) + `fecha_max` formatted `font-mono` in Chile tz (reuse `FECHA_CHILE`/`fechaCorta`). A row without a traceable source is not shown standalone (germ rule E).
- **Empty / suppression state:** when a row has `supresion_causa != null`, render the cause verbatim as the tile body (`text-sm text-muted-foreground`) — e.g. "Sin datos frescos de esta fuente", "Sin sesiones agendadas en las fuentes consultadas". NEVER an empty list, NEVER a mute "0", NEVER "sin movimiento". A conteo of 0 with `supresion_causa` set is a suppression, not a fact.
- **`(sin materia)` tolerance:** `agrupacion_materia` rows may carry `materia = '(sin materia)'` (proyecto.materia NULL in PROD — honest degradation). Render the label verbatim; do NOT hide the row, do NOT fabricate a topic, do NOT crash.
- **Real read error → throw** (germ rule D / #34): a genuine RPC error throws (surfaces error boundary); never `?? []` that fabricates "sin datos". Suppression is ONLY the legitimate 0-rows path signalled by `supresion_causa`.

## Honesty Contract in UI (LOCKED — existential risk #1)

| Rule | UI enforcement |
|------|----------------|
| Fuente + fecha on every tile | footer "datos al {fecha_max}" + per-source label; mono date, Chile tz |
| Suppression renders its cause | `supresion_causa` shown verbatim; never empty list / never "sin movimiento" |
| No cross-cámara ranking (T-52-13) | rows keyed by `cobertura_camara` are shown side-by-side WITHOUT ordering by `conteo` across chambers; no "top/los más/la más activa"; the cámara bar is provenance, not a leaderboard |
| Cámara coverage declared | `cobertura_camara` printed on velocity/agenda rows (incl. `(sin cámara)` and `2022-2026 (piso de corpus)` literals) — the asymmetry (Cámara 25.741 vs Senado 20.357 events) is coverage/style, stated, never activity |
| No inferred intention/causality | factual framing only; anti-insinuación linter must pass with new vocab |

**Anti-insinuación denylist extension (FIRST commit, before any new copy):** the new panel
vocabulary must stay linter-green. Words like **"último momento", "revivido", "exprés",
"madrugada", "a última hora"** are NEVER used. Extend `TERMINOS_PROHIBIDOS` /
`SUPERFICIES_PANEL` in `anti-insinuacion-guard.test.ts` BEFORE writing panel copy (Pitfall
#6 + #3). Any locked legend that NEGATES a prohibited term must be registered verbatim in
`NEGACIONES_LOCKED` before the surface enters the scan.

- If the BrowserOS MCP is down, the orchestrator (which holds the MCP) closes the gate.

## Copywriting Contract

All copy Spanish, factual, linter-safe. Numbers/dates/boletines in `font-mono`.

| Element | Copy |
|---------|------|
| Panel section (no new hero) | (hero LOCKED — no new heading above the panel) |
| velocity tile title | `Movimiento reciente` |
| velocity framing | `{N} trámites en 7 días` + cobertura chip (`Cámara` / `Senado` / `(sin cámara)`) |
| urgencias tile title | `Urgencias del Ejecutivo` |
| urgencias framing | `{N} urgencias fechadas en 30 días` |
| agenda tile title | `Agenda próxima` |
| agenda framing | `{N} citaciones próximas` (+ agenda_sala sub-block or its `supresion_causa`) |
| nuevos_ingresos tile title | `Nuevos ingresos` |
| nuevos_ingresos framing | `{N} proyectos ingresados en 7 días` + `2022-2026 (piso de corpus)` note |
| archivados tile title | `Archivos y retiros` |
| archivados framing | `{N} movimientos de archivo o retiro fechados (30 días)` |
| agrupacion_materia tile title | `Por materia` |
| agrupacion_materia label | verbatim `materia`, tolerate `(sin materia)` |
| Empty/suppression body | render `supresion_causa` verbatim (e.g. `Sin datos frescos de esta fuente`, `Sin sesiones agendadas en las fuentes consultadas`, `Sin urgencias fechadas en la ventana`) |

coincidence of timing never implies relation.
