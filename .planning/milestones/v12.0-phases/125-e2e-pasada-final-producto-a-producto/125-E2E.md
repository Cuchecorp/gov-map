### §0.3 Régimen de la corrida (probado por comando en §6.3)

- `curl` **secuencial**, **1 s** entre requests, User-Agent identificatorio, **sólo** contra el Worker
  propio. Contra fuentes gubernamentales: **2,89 s/request** medidos (mínimo instantáneo 2.501 ms),
  robots.txt primero, muestra estratificada acotada — **jamás ráfagas, jamás crawl exhaustivo**.
- SQL: `psql -tA` **read-only**, `select` exclusivamente, queries **verbatim** de 122.
  `SUPABASE_DB_URL` **jamás** expandida ni ecoada.
- **Cero** fixes de código, **cero** DDL/DML, **cero** deploy (más allá del de §0.1), **cero** flips de
  flag, **cero** PII, **cero** navegación a `/admin/revisar-entidades`.

### §0.4 Gotchas de método que gobiernan toda cifra de este documento

Se listan porque cualquier fase futura pisará las mismas minas, y porque varias cifras habrían sido
**falsas** sin ellos.

| # | gotcha | consecuencia |
|---|---|---|
| G-1 | el HTML del Worker es **una sola línea** ⇒ `grep -c` topa en **1** | todas las cifras usan `grep -o … \| wc -l`; `grep -c` **no se usa para contar** |
| G-2 | React intercala `<!-- -->` entre texto y dígitos | ningún literal pelado con número matchea; se mide por offset (`grep -bo`) + recorte + extracción numérica |
| G-3 | el literal viaja **duplicado** (payload RSC + HTML real) | todo conteo de copy se duplica si no se declara la capa |
| G-4 | `grep -i` + `-F` devuelve **0 SIEMPRE** en GNU grep 3.0 | prohibido combinarlos; una celda contaminada se recalculó con `-oi` |
| G-5 | `set -o pipefail` + `grep -q` ⇒ **exit 141** por SIGPIPE | existencia de commits por `git cat-file -t`, nunca `git log \| grep -q` |
| G-6 | `bros-cli` imprime `CDP request timeout` y **sale con 0** | el retry por `\|\|` nunca dispara; **12 de 21 capturas** se perdieron en silencio en la primera corrida |
| G-7 | `get_page_content`/`innerText` son **ciegos** al contenido de Suspense (645 B vs **914.556** en `textContent`) | todo fragmento hidratado se leyó de `document.body.textContent` |
| G-8 | `take_snapshot` sub-reporta interactivos (1 botón vs 16 reales) | sirve como prueba de *presencia*, **no** como denominador |
| G-9 | un glob de guards sin `cd app/` da *"No test files found"* con **exit 0** | falso verde; los 12 guards se corrieron **por nombre explícito** (§6.2) |
| G-10 | en waves paralelas sobre un mismo checkout, `git commit --amend` es **inseguro** | el 125-05 reescribió sin querer el commit del 125-03; los commits atómicos por plan **no** están garantizados sin worktrees separados |
