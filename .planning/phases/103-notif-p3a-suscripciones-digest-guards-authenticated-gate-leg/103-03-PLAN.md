| Boundary | Description |
|----------|-------------|
| browser form → Server Action | untrusted FormData; user_id must be server-derived |
| email link (raw token) → confirmar/baja | opaque token = the only authorization, no session |
| flag env → DOM | OFF must mean absent, not hidden |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-08 | Tampering / EoP | client-forged user_id on subscribe | mitigate | user_id from getClaims() sub server-side + RLS with check backstop |
| T-103-09 | Spoofing | OTP relay / email echo in error | mitigate | validation-before-GoTrue + generic error, never echo email/token (WR-02) |
| T-103-10 | Tampering | unsubscribe token forgery/enumeration | mitigate | opaque 256-bit random, sha256-hashed at rest, non-derivable |
| T-103-11 | Information Disclosure | Seguir surface leaks when flag OFF | mitigate | return null before any DOM/RPC; RTL test asserts absence |
| T-103-12 | Integrity | CSP widened for auth | accept/mitigate | auth 100% server-side; browser never calls Supabase; connect-src 'self' LOCCKED (unchanged) |
| T-103-SC | Tampering | npm/pip/cargo installs | mitigate | ZERO new external packages this plan; token = node:crypto builtin |
</threat_model>
