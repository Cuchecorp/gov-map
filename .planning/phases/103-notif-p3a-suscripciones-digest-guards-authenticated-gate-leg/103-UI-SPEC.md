# Phase 103 — UI Design Contract

> Visual and interaction contract for NOTIF P3a — Suscripciones + digest + guards authenticated + gate legal.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Pre-populated from the EXISTING Observatorio design system (Tailwind v4 + civic tokens + shadcn primitives copied verbatim into `app/components/ui/`). This phase adds surfaces; it does NOT introduce new tokens.

| # | Surface | Type | Notes |
|---|---------|------|-------|
| S1 | `/cuenta` | New route (RSC + Server Actions) | Login OTP por email (enviar código → verificar código), lista de suscripciones, preference center mínimo (frecuencia digest = fija "diario L–V" declarada, unsubscribe), estado de consentimiento. ## Spacing Scale

Declared values (Tailwind v4 default `rem` steps, all multiples of 4 at 16px root):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`) | Icon-to-text gaps, inline dot separators |
| sm | 8px (`gap-2` / `space-y-2`) | Label→input, compact stacks (login form fields) |
| md | 16px (`gap-4` / `px-4`) | Default element spacing, page horizontal padding on mobile |
| lg | 24px (`gap-6` / `md:px-8`) | Section padding, gap between subscription cards |
| xl | 32px (`py-8` / `space-y-8`) | Between major blocks on `/cuenta` (login / lista / preferencias / consentimiento) |
| 2xl | 48px (`py-12`) | Confirmar/baja page vertical centering block |
| 3xl | 64px (`md:py-16`) | Page-level top/bottom on `/cuenta` desktop |

Exceptions:
- **44px minimum touch target** for the "Seguir" button and all `/cuenta` interactive controls (`min-h-[2.75rem]` — matches `.net-filtros__tipo` / `.net-b-pager__btn` precedent). shadcn `Button` `size="default"` is `h-10` (40px); on mobile use `size="lg"` (`h-11` = 44px) or add `min-h-[2.75rem]`.
- **Email template** uses table-based inline spacing (`padding: 16px 24px`) — cannot use utility classes; mirror the 8-point scale in raw px.

## Typography

Reuse the existing scale (Tailwind v4 defaults, already used sitewide via `text-*` and `var(--text-*)`). Exactly 4 roles, 2 weights:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 (`leading-normal`) |
| Label | 14px (`text-sm`) | 600 (`font-semibold`) | 1.5 | 
| Heading | 20px (`text-xl`) | 600 (`font-semibold`) | 1.3 (`leading-snug`) |
| Display (page H1) | 24px (`text-2xl` desktop) / 20px (`text-xl` mobile) | 600 (`font-semibold`) | 1.2 (`leading-tight`) |

- Weights: **exactly two** — `font-normal` (400) and `font-semibold` (600). NO 500/700 introductions.
- Timestamps/tokens (in provenance tooltip, consent record): `font-mono text-xs` (12px), matching `ProvenanceBadge` precedent.
- Body copy defaults to `text-sm` (14px) sitewide — do NOT bump to 16px (would diverge from every existing ficha).
- **Email template:** body 16px / headings 20px / footer+legal 12px, all `line-height: 1.5`, weights 400/700 (email clients render `600` inconsistently → use `700` for bold in email ONLY).

## Color

All colors via existing HSL CSS variables — **CERO hex nuevos** (candado de régimen cero-hex, LOCKED; guardado por bento cero-hex source-scan). 60/30/10 split inherited:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` crema `40 33% 97%` | Page background, `/cuenta` surface |
| Secondary (30%) | `hsl(var(--card))` `40 30% 99%` + `hsl(var(--muted))` `40 20% 93%` | Subscription cards, form containers, empty-state panels |
| Accent (10%) | `hsl(var(--accent-product))` petróleo `183 38% 26%` | See reserved-for list below |
| Destructive | `hsl(var(--destructive))` `0 72% 42%` | Unsubscribe / "Dejar de seguir" / "Cerrar sesión" affordances only |

**Accent (petróleo) reserved for:**
- The primary CTA fill on `/cuenta` ("Enviar código", "Verificar código") — via `Button` default OR petróleo per existing convention.
- Active/"Siguiendo" state of the Seguir button (filled petróleo when following; outline when not-following).
- Focus-visible outlines (`outline: 2px solid hsl(var(--accent-product))`, matching `.net-b-row:focus-visible`).
- Inline links to source/detail (`.net-b-link` precedent: petróleo + underline).
- Anti-insinuation microcopy left-border (`border-left: 3px solid hsl(var(--accent-product))`, matching `.net-microcopy`).

**Never** use `--camara`/`--senado` civic colors as fills on subscription rows or the Seguir button (anti-insinuation LOCKED — same rule as `.net-chip`: institutional color is a 1.5px border at most, never a fill implying endorsement). A subscription to a parlamentario may show a camera chip (bordered, `.net-chip--camara`/`--senado`) but the card itself stays neutral card/border.

**Email:** inline hex is UNAVOIDABLE (email clients don't resolve CSS vars). Bake the token values as hex once in the template with a comment mapping each back to its token: background `#F9F6F0` (`--background`), card `#FDFBF7` (`--card`), border `#E3DDD3` (`--border`), petróleo link `#2A5859` (`--accent-product`), muted text `#5C6373` (`--muted-foreground`). This is the ONE sanctioned hex island; the site surfaces stay hex-free.

## Interaction / State Contract

| Surface | States required |
|---------|-----------------|
| `/cuenta` (logged out) | Login form (send) → code form (verify) → error (generic). No email/token ever rendered back. |
| `/cuenta` (logged in) | Session banner + subscriptions list (populated OR empty state) + frequency copy + consent status. |
| Seguir button | `not-following` (outline) / `following` (filled) / `pending` (disabled during Server Action) / `logged-out` (redirects to `/cuenta?next`). AUSENTE del DOM cuando `NOTIF` flag OFF. |
| S3 confirmar | success / invalid-or-expired-token. |
| S4 baja | success / invalid-or-used-token. |
| Email | HTML + plain-text multipart; per-subscription groups; no-news note when a group is empty; footer unsubscribe always present. |

**Loading:** Server Actions block the submitting control (disable + `disabled:opacity-50`, existing Button behavior). No client spinners (no client Supabase). Optional `Skeleton` for the subscriptions list on RSC stream.

**Accessibility:** every interactive control ≥44px touch target; `focus-visible` petróleo outline; form labels tied via `htmlFor`; the Seguir button announces state (`aria-pressed`); `/notificaciones/*` landing pages set `robots: noindex`.
