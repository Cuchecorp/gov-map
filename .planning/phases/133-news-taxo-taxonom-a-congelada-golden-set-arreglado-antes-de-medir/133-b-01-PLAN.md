## Idiom de medición — OBLIGATORIO

`passWithNoTests: true` está ACTIVO (`packages/news/vitest.config.ts:10`) y los argumentos de
`vitest run` son **filtros de nombre de archivo, no rutas**: un filtro que no casa nada sale
**rc=0 sin correr nada**. Por eso **jamás se asserta el exit code solo** — se asserta el conteo
impreso.

`grep -oE 'Tests[^0-9]+[0-9]+ passed'` **sin `NO_COLOR=1` sale rc=1 y no devuelve nada** (los ANSI
rompen el grep). Verificado en 133-a.

```bash
NO_COLOR=1 <comando de vitest> 2>&1 | tee /tmp/LOG.log
N=$(grep -oE 'Tests[^0-9]+[0-9]+ passed' /tmp/LOG.log | grep -oE '[0-9]+')
```

`-t` de vitest es **REGEX**: `(1b)` selecciona 0 tests con rc=0. Al filtrar por nombre hay que
escapar los paréntesis **y** assertar que seleccionó exactamente 1 test:
`test "$N" -eq 1`.

Base congelada en 133-a: **268 passed** (`133-b-ESTADO-VENTANA.md:106`). Se conserva `-gt 268` como
piso secundario de sanidad; **el criterio fuerte es el DELTA propio del plan**.

**dos líneas** y `test` sale rc=2 — falso rojo permanente. Reproducido. El idiom correcto:

```bash
get () { echo "$L" | sed -nE "s/.*(^| )$1=([0-9]+).*/\2/p"; }
```
