`Q-22` — esquemas alcanzables por `anon`/`authenticated` (la Data API sirve lo que PostgREST expone y
el rol puede usar):
```sql
select n.nspname,
       has_schema_privilege('anon', n.nspname, 'USAGE')          as usage_anon,
       has_schema_privilege('authenticated', n.nspname, 'USAGE') as usage_authenticated
from pg_namespace n
where n.nspname not like 'pg\_%' and n.nspname <> 'information_schema'
order by 1;
```

`Q-23` — roles del proyecto y sus atributos peligrosos:
```sql
select rolname, rolsuper, rolbypassrls, rolcanlogin, rolcreaterole, rolcreatedb
from pg_roles
where rolname in ('anon','authenticated','service_role','authenticator','postgres')
order by 1;
```

`Q-24` — Splinter 0014: extensiones instaladas en `public` (contaminan el esquema expuesto):
```sql
select e.extname, n.nspname as esquema

order by 2, 1;
```

una tabla con columna `¿esperado?`: `public` con USAGE es el diseño de PostgREST y **no** es offender;
