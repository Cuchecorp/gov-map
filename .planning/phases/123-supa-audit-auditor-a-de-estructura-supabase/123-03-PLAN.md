`Q-12` — toda función de `public` con su exposición real por rol:
```sql
select p.proname,
       pg_get_function_identity_arguments(p.oid)          as args,
       p.prosecdef                                        as security_definer,
       has_function_privilege('anon', p.oid, 'EXECUTE')          as exec_anon,
       has_function_privilege('authenticated', p.oid, 'EXECUTE') as exec_authenticated,
       has_function_privilege('service_role', p.oid, 'EXECUTE')  as exec_service_role
from pg_proc p
join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and not exists (select 1 from pg_depend d where d.objid = p.oid and d.deptype = 'e')
order by exec_anon desc, p.proname;
```

`Q-13` — acotamiento de cada función expuesta a `anon` (bounded = `LIMIT` explícito **y**
`statement_timeout`):
```sql
select p.proname,
       (lower(p.prosrc) ~ 'limit[[:space:]]+[0-9]')          as tiene_limit,
       (lower(p.prosrc) like '%statement_timeout%'
        or array_to_string(coalesce(p.proconfig,'{}'), ',') like '%statement_timeout%') as tiene_timeout,
       array_to_string(coalesce(p.proconfig,'{}'), ',')      as proconfig
from pg_proc p
join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and has_function_privilege('anon', p.oid, 'EXECUTE')
  and not exists (select 1 from pg_depend d where d.objid = p.oid and d.deptype = 'e')
order by tiene_limit asc, tiene_timeout asc, p.proname;
```

`Q-14` — superficie PII de las RPCs expuestas: firmas de retorno que nombren columnas sensibles:
```sql
select p.proname, pg_get_function_result(p.oid) as retorno
from pg_proc p
join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and has_function_privilege('anon', p.oid, 'EXECUTE')
  and pg_get_function_result(p.oid) ~* '(rut|email|correo|telefono|donante_id|direccion)'
  and not exists (select 1 from pg_depend d where d.objid = p.oid and d.deptype = 'e');
```

Entregar: tabla completa de `Q-12`; tabla de `Q-13` con una columna `bounded` derivada
(`tiene_limit AND tiene_timeout`) y **una fila de offender por cada `false`**; salida literal de `Q-14`
(si vacía, `(0 filas)` + veredicto `conforme` junto a la query).

Nota de método obligatoria en el fragmento: `Q-13` es una **heurística sobre `prosrc`**; una RPC que
acota por `fetch first N rows only` o por parámetro `p_limit` con default no matchea el regex. Toda
fila `tiene_limit = false` se revisa a mano leyendo `pg_get_functiondef(p.oid)` **antes** de declararla

seguridad sino de exactitud, y se ancla en el backlog de la Phase 124 (ver 123-06).
